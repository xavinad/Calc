# Compilation de l’APK

Prérequis : Android Studio récent, JDK 17, SDK Android API 36.

1. Ouvrir le dossier `MonAlcoolemie-Android` dans Android Studio.
2. Laisser Gradle synchroniser le projet.
3. `Build > Build APK(s)`.
4. APK de débogage : `app/build/outputs/apk/debug/app-debug.apk`.

Aucune permission Internet, GPS, contacts ou stockage n’est demandée.
